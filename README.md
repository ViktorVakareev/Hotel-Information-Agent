# Hotel-Information-Agent
An AI-powered agent that can answer guests questions for a hetel.

## Features
- Amenities Inquiry: Answers guest questions regarding hotel amenities.
- Restaurant Information: Provides details on restaurant hours and dining options.
 -Check-out Assistance: Responds to queries about check-out times and procedures.

## Architecture and Technologies
- Platform: Azure AI Foundry
- AI Model: GPT-5-mini
- System Instructions: "You are a helpful hotel concierge attending to guest inquiries and concerns. Be polite, accommodating, and maintain a great attitude with every guest."
